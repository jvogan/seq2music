# Asset provenance

The protein-note artwork was generated specifically for Seq2Music on 2026-08-31 using OpenAI image generation, without third-party source images. The 512×512 logo is the master artwork; the 128×128 composer image is its interface-sized derivative. Jacob Vogan releases both with this repository under the MIT License.

The FASTA, PDB, and mmCIF files under `examples/` are original synthetic fixtures authored for Seq2Music demonstrations and automated tests. They are not derived from external sequence, structure, research, or clinical datasets.

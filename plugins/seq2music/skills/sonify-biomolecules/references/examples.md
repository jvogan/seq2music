# Example requests

- “Encode this local protein FASTA as music, decode the MIDI back to FASTA, and prove the normalized sequence hash matches.”
- “Decode this Seq2Music MIDI and tell me whether it is exact from embedded metadata or also matched to its manifest.”
- “Show me the grand-staff score, then decode the generated MusicXML and WAV back to FASTA.”
- “Quantize this local WAV into a protein sequence, and clearly label the result as lossy.”
- “Map this monophonic MusicXML melody into RNA and return the note-by-note receipt.”
- “Compare these reference and mutant proteins as a stereo audible diff with a position-by-position change ledger.”
- “Sonify this pre-aligned family. Let consensus identity set the root and column entropy set the interval.”
- “Render chain A, model 2 of this PDB as a residue-order geometry trace and explain which contact-count cues produce chords.”
- “Sonify this coding DNA as a base track and show the base-to-note mapping.”
- “Verify that none of the generated artifacts changed since the run manifest was created.”

Good follow-up analyses include locating audible changes in the CSV, comparing the audio with a shuffled control, and running a blinded user study.

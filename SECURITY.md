# Security

Seq2Music processes local biological, audio, score, and structure files. Security reports are especially useful for path traversal, unsafe archive or XML handling, resource-exhaustion bypasses, manifest verification errors, and cases where an exact decode accepts modified carrier data.

When this repository is published, use GitHub's private vulnerability reporting if it is enabled. Avoid posting exploit details, private datasets, credentials, or identifying file paths in a public issue.

Supported security fixes target the latest release on the default branch.
